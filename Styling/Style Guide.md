# Style Guide
Frontend web development is like three musketeers (HTML: layout, CSS: style, and JavaScript: interaction), and mastering each of them is essential to becoming a good developer.

Of these three, JavaScript is the most discussed, HTML is what you get started with, but CSS is something that gets the least attention.

But in my opinion, all of these trees have equal importance, and as frontend developers, we should understand each of them equally in depth.

The emergence of modern CSS frameworks like Bootstrap, Foundation, and Tailwind, has shifted the focus towards faster deliveries, which is really important, but as you grow as a developer, having a basic understanding will be extremely essential; after all, without a solid understanding of CSS, these frameworks could have emerged.

Applications such as the E-Commerce app, blogs, and admin dashboards are very style-heavy, and every minute detail helps in performance improvements.

In this article, we are going to learn the CSS with SMACSS (Scalable and Modular Architecture for the CSS) methodologically and see the different ways to write object oriented CSS.
