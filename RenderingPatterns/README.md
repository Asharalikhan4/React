# 🎨 React Rendering Patterns & Component Architecture

> Comprehensive guides exploring how modern React components communicate, compose, and hydrate across client and server boundaries.

---

## 📑 Articles & Guides Included

1. [**Compound Component Pattern**](./Compund%20Pattern%20in%20React.md)  
   Build declarative, flexible components sharing implicit state via React Context (e.g., Tabs, Accordions, Dropdowns).

2. [**Container & Presentational Pattern**](./Container%20Presentational%20Pattern%20in%20React.md)  
   Isolate stateful data fetching logic from dumb UI components for testability and reusability.

3. [**Higher-Order Component Pattern (HOC)**](./Higher-Order%20Component%20Pattern%20in%20React.md)  
   Reuse cross-cutting logic through functional component composition.

4. [**Advanced Component Patterns**](./Advance%20React%20Component%20Patterns.md)  
   Deep dive into Render Props, State Reducer patterns, and Inversion of Control.

5. [**Provider Data Passing in React**](./Provider%20Data%20Passing%20in%20React.md)  
   Eliminating prop drilling using scoped providers and optimal Context splitting.

6. [**Client-Side Rendering (CSR) vs Server-Side Rendering (SSR)**](./Client-side%20rendering%20vs%20Server-side%20rendering.md)  
   Comprehensive architectural tradeoffs: TTFB, FCP, LCP, SEO considerations, and hydration overhead.

7. [**Selective vs Progressive Hydration**](./Selective%20vs%20Progressive%20Hydration.md)  
   Modern React 18 streaming architecture and selective hydration triggered by user interaction.

8. [**Incremental Static Regeneration (ISR) vs SSG**](./Incremental%20Static%20Re-Rendering%20vs%20Server-Side%20Generated.md)  
   Static caching paradigms and on-demand background regeneration.
